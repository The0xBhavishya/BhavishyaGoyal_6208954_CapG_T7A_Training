# Playwright Test Project

This project contains automated tests using Playwright, Jest, and Mocha.

## Structure

- `Day1_to_9/`: Learning materials and examples from days 1 to 9
- `Playwright/`: Main test suites and configurations
  - `MochaProject/`: Mocha-based tests
  - `PageObjectModel/`: Page object models for different sites
  - `Playwright/`: Playwright test files organized by days
  - `tests/`: Additional test files
- `testdata/`: Test data files

## Setup

1. Install dependencies: `npm install`
2. Run tests: `npx playwright test`

## Technologies

- Playwright
- Jest
- Mocha
- TypeScript
